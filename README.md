## 月付改年付：先确认不会把低价改没

月付改年付本身在后台的 Change billing cycle（修改账单周期）页面就能操作，普通在售套餐改完之后，账单按当前年付价格计算，长期用能省下那 2 个月的钱。**但传家宝套餐、历史低价套餐和已经下架的限量套餐是例外**——这类套餐一旦修改续费周期，账单会按当前价格重新计算，原来的低价直接丢失，不可恢复。

举个具体的例子：假如你手里有一台当年 $49.99/年 的 CN2 GIA-E 限量版，为了“年付更划算”去改周期，结果可能是续费价直接跳到现价，反而亏了。

修改前建议逐条核对：

1. 打开 Change billing cycle 页面，看清显示的新周期金额，确认它低于你现在的续费价再保存；
2. 已经生成的续费账单，无法通过改周期追溯调整；
3. 修改周期不是重新购买，不能顺便使用新的优惠码；
4. 想清楚改成年付后是否确定长期保留这台 VPS。

> 一句话判断：只要新周期金额高于你现在的续费价，就别改。年付省的那点钱，抵不上丢掉一个传家宝价格。

## 想一次性买好几年？用账户余额代替

搬瓦工没有多年付选项，但有个变通办法：先给账户充值（Add Funds），余额足够时 VPS 到期会自动续费。比如一款 $49.99/年 的套餐，账户里充 $150，相当于提前锁定 3 年，不用每年惦记续费这回事。

两个细节值得注意。一是充值只支持信用卡和 PayPal，不能用支付宝——虽然购买和续费本身都支持支付宝；二是不想自动续费的话，可以在后台手动关闭，这个开关默认是打开的。
